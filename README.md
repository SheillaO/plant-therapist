This repository hosts a lighthearted landing page for Plant Therapist, an emotional support app for chronic houseplant killers. The project serves as a hands-on continuous deployment laboratory to practice building dockerized environments, running automated tests, and deploying live production containers via automated pipelines.

🛠️ DevOps & Tech Stack

• CI/CD Pipeline: GitHub Actions for automated building, linting, testing, and continuous deployment tracking.
• Containerization: Docker for packaging the web application assets and environment dependencies.
• Frontend: Standard, semantic HTML5, custom CSS3, and dynamic vanilla JavaScript client scripts.
